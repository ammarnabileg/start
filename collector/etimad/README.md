# سحّاب منافسات اعتماد

اعتماد (tenders.etimad.sa) محمي ضد البوتات، فطلبات PHP العادية بترجع صفحة تحدي مش بيانات. السحّاب ده بيفتح صفحة الزوار العامة بمتصفح حقيقي، ويقرا **المنافسات النشطة** صفحة صفحة على مهل، ويبعتها للمنصة.

## التشغيل على سيرفر (VPS)

```bash
cd collector/etimad
npm install
npx playwright install --with-deps chromium
```

من صفحة **المنافسات الحكومية** في المنصة (بحساب مدير المنصة) ← زرار **السحّاب**: اعمل توكن وانسخ الرابط والتوكن.

```bash
PLATFORM_URL=https://panel.example.com INGEST_TOKEN=التوكن node collector.js
```

كل ساعتين من crontab:

```
17 */2 * * * cd /opt/collector/etimad && PLATFORM_URL=https://panel.example.com INGEST_TOKEN=التوكن node collector.js >> collector.log 2>&1
```

## بيعمل إيه بالظبط

- أول تشغيل في اليوم: **لفة كاملة** على كل المنافسات النشطة (حوالي 100 صفحة × 24). ده بيحدّث المواعيد اللي اتمدت.
- باقي اليوم: **تحديث سريع**. بيقف لما يلاقي صفحتين متتاليتين كلها منافسات شافها قبل كده.
- بين كل صفحة والتانية 8 لـ 12 ثانية (`DELAY_MS`)، عشان الضغط على الموقع يبقى أقل ما يمكن.
- لو اعتماد رجّع حاجة مش بيانات (الحماية اتغيرت مثلًا)، بيقف ويبعت ملاحظة للمنصة، والمنصة بتعرض "البيانات متأخرة".

## خيارات

| المتغير | الافتراضي | المعنى |
|---|---|---|
| `MAX_PAGES` | 150 | أقصى عدد صفحات في التشغيلة |
| `DELAY_MS` | 8000 | الانتظار بين الصفحات |
| `FULL=1` | — | لفة كاملة دلوقتي |
| `DRY=1` | — | تجربة من غير إرسال للمنصة |
| `STATE_FILE` | `state.json` | الأرقام اللي اتشافت قبل كده |

## تنبيه

السحّاب بيقرا الصفحات العامة المتاحة لأي زائر. بس الالتفاف على حماية البوتات غالبًا ضد شروط استخدام اعتماد، وممكن عنوان السيرفر يتحظر. خليه بطيء، ومتشغلوش أكتر من مرة كل ساعتين. والبديل الآمن مصدر رسمي أو مزود بيانات مرخص، والمنصة بتستقبل منهم بنفس الرابط.
