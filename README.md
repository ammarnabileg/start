# لوحة النشر (مربوطة بـ Zernio)

نشر وجدولة المحتوى، والرد على الرسائل والتعليقات، لكل حساباتك من مكان واحد.

## التسطيب أول مرة

1. من لوحة الاستضافة (cPanel ← **MySQL Databases**):
   - اعمل قاعدة بيانات جديدة.
   - اعمل مستخدم جديد بكلمة سر.
   - ضيف المستخدم للقاعدة واختار **ALL PRIVILEGES**.
   - اكتب الثلاث حاجات دول في ورقة: اسم القاعدة، اسم المستخدم، كلمة السر.
2. من **File Manager** افتح `public_html`، ارفع ملف الـ zip، ودوس عليه **Extract**.
3. افتح موقعك في المتصفح. هيوديك لصفحة التسطيب لوحده.
4. اكتب بيانات القاعدة ← **التالي** ← اسم الموقع وحسابك ← **تسطيب**.
5. ادخل بالإيميل وكلمة السر. هتلاقي نفسك في **شركاتي**: اعمل شركة وحط مفتاح Zernio بتاعها.

## الشركات والفريق

- كل شركة ليها مفتاح Zernio وحسابات وفريق منفصلين. محدش يشوف شركة مش عضو فيها، حتى مدير النظام.
- أي حد يقدر يعمل حساب ويعمل شركاته. المدير يقدر يقفل التسجيل من **إعدادات النظام**.
- صاحب الشركة يضيف الفريق من **فريق الشركة**:
  - **بالإيميل:** لو الشخص عنده حساب، الدعوة بتظهرله جوه البرنامج يوافق أو يرفض. لو معندوش، بيطلعلك لينك تبعتهوله.
  - **بلينك عام:** أي حد معاه اللينك يدخل. الغيه لما تخلص.
- البرنامج **مش بيبعت إيميلات**. اللينكات بتتبعت بإيدك (واتساب مثلاً).
- الصلاحيات: **صاحب شركة** (كل حاجة) أو **محرر** (ينشر ويرد على الرسايل والتعليقات).

## التحديث

1. ارفع ملف الـ zip الجديد واعمله **Extract** فوق الملفات القديمة (وافق على الكتابة فوقها).
2. افتح `موقعك/setup.php`. الموقع هيوديك هناك تلقائياً لو فيه تحديث.
3. اكتب إيميل وكلمة سر مدير النظام ← **تحديث البيانات**.

بياناتك ومنشوراتك وإعداداتك مش بتتمسح في التحديث. ملف `config.php` اللي فيه بيانات القاعدة مش موجود في الـ zip، فمش هيتكتب فوقه.

## متطلبات السيرفر

PHP 7.4 أو أحدث، و MySQL أو MariaDB، وإضافات: pdo_mysql و curl و mbstring و fileinfo. أغلب الاستضافات فيها كل ده جاهز. صفحة التسطيب بتكشف أي حاجة ناقصة.

## للمطورين

- `app/migrations.php`: تحديثات قاعدة البيانات. أضف مفتاح جديد بالأسفل، ومتعدلش القديم.
- `app/version.php`: زوّد الرقم مع كل إصدار. ده اللي بيخلي الموقع يطلب التحديث.
- `app/obsolete.php`: ملفات اتشالت ومحتاجة تتمسح من السيرفر وقت التحديث.
- ابني الـ zip بـ `bash build.sh`.
